# PURPOSE

Dokumen ini mendefinisikan governance pada SMART Platform.

Dokumen ini menjadi standar untuk:

- Pengambilan keputusan teknologi.
- Perubahan sistem.
- Quality Control.
- Development Standard.
- Security Governance.
- Platform Evolution.

---

# GOVERNANCE VISION

SMART Platform harus berkembang secara terarah.

Prinsip:

> Growth without losing control.
